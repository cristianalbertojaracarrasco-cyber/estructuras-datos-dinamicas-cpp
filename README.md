# Biblioteca de Estructuras de Datos Dinámicas en C++

Trabajo Colaborativo — Estructura de Datos Dinámicos, CFT CENCO
Docente: Raúl G. Villegas T.

Biblioteca que implementa con punteros y memoria dinámica:

| Archivo | Contenido |
|---|---|
| `ListaEnlazada.h` | Lista enlazada simple: `insertar`, `eliminar`, `buscar`, `mostrar` |
| `Pila.h` | Pila LIFO: `push`, `pop`, `estaVacia`, `mostrar` |
| `Cola.h` | Cola FIFO: `InsertarQ` (enqueue), `EliminarQ` (dequeue), `estaVacia`, `mostrar` |
| `main.cpp` | Programa con ejemplos de uso de las tres estructuras |

## Compilar y ejecutar

```bash
g++ -std=c++11 -Wall main.cpp -o estructuras
./estructuras          # En Windows: estructuras.exe
```
